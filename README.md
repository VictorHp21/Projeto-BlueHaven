# 🧢 BlueHaven

BlueHaven é um aplicativo **low-code** desenvolvido na plataforma **Appsmith**, voltado para o gerenciamento de uma loja de moda streetwear.  
O sistema realiza operações **CRUD** completas com **vendedores, clientes, vendas, produtos em estoque, pedidos e fornecedores**, proporcionando uma experiência prática e intuitiva.

---

## 🚀 Tecnologias Utilizadas

- **Appsmith** – Plataforma low-code para desenvolvimento do app.  
- **MySQL** – Banco de dados relacional.  
- **Aiven** – Hospedagem e gerenciamento do banco de dados em nuvem.  

---

## ⚙️ Funcionalidades

- 👕 **Gerenciamento de Produtos**: Adicione, atualize, consulte e remova itens do estoque.  
- 🛒 **Controle de Pedidos**: Crie e acompanhe pedidos realizados por clientes.  
- 💼 **Gestão de Vendedores**: Cadastre vendedores e visualize suas vendas.  
- 👥 **Cadastro de Clientes**: Registre e edite informações de clientes.  
- 🚚 **Controle de Fornecedores**: Mantenha os dados de fornecedores organizados.  

---

## 🧭 Instruções de Uso

1. **Acesse a tela de Login.**
   - Cadastre-se informando **nome**, **e-mail** e **senha**.
   - Após o cadastro, utilize o **e-mail e senha** para realizar o login.

2. **Navegação pelas telas:**
   - Cada tela representa uma entidade (Clientes, Vendedores, Pedidos, etc.).
   - Use os botões disponíveis para realizar operações de:
     - ➕ **Adicionar** novos registros  
     - ✏️ **Editar** informações  
     - 🗑️ **Excluir** registros existentes  
     - 🔍 **Visualizar** dados cadastrados

3. Todas as ações são automaticamente refletidas no **banco de dados hospedado na Aiven**.

---

## 🧩 Estrutura de Dados (Resumo das Entidades)
